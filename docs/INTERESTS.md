## 如何解读

自有项目比单纯 Fork 更能表明投入方向；但主语言、仓库数量和更新时间均不能证明投入时长或技能等级。Fork 的更新时间可能来自上游，不能当作个人活跃记录。没有描述的项目保留在“其他探索”，不凭名字编造用途。

## 后续可扩展

- 人工确认项目阶段、用途与展示顺序。
- 按月比较公开快照，观察方向变化。
- 经本人选择后再引入 Star 列表或公开 README 文本，增加证据覆盖。
